# LEO Club Website

A modern, responsive single-page website for LEO Club, built with React and Tailwind CSS.

## Features

- **Sticky Navigation** with scroll detection and smooth transitions
- **Hero Section** with animated gradient background and floating badge
- **Our Story** with split layout and decorative gold border
- **Core Pillars** grid with hover effects and glow animations
- **Key Events** showcase with upcoming and past events
- **Leadership Team** grid with profile cards
- **Legacy/Impact Stats** with animated counters
- **Resources** section with downloadable materials
- **Footer** with CTAs and contact information
- **Fully Responsive** mobile design with hamburger menu
- **Smooth Scroll** animations throughout

## Design

- **Colors**: Deep navy blue (#0A1F44) primary, warm gold (#F5B800) accent
- **Typography**: Playfair Display for headlines, DM Sans for body text
- **Aesthetic**: Bold, editorial, civic pride with luxury nonprofit feel

## Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Technologies

- React 18
- Vite
- Tailwind CSS
- Lucide React (icons)

## Customization

To customize the content:

1. Update the text and data in each component file
2. Replace placeholder images in the components
3. Modify colors in `tailwind.config.js`
4. Add your own Google Fonts in `index.html`
